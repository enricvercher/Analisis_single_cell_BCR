# Analisis_single_cell_BCR

This repository contains the final master's project for the Master's Degree in Bioinformatics and Biostatistics.

It includes an analysis of B cell receptor (BCR) repertoires from tumor-infiltrating B cells in a murine model of pancreatic ductal adenocarcinoma. The study involves six mice and focuses on clonal expansion, phenotype characterization, and somatic hypermutation patterns, with the ultimate goal of identifying tumor-specific BCRs.
